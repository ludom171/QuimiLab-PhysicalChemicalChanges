# Demo

This folder contains a short demonstration video of the virtual prototype developed for the laboratory practice **Physical and Chemical Changes**.

## File

- `Prototype_Demo.mp4` — Demonstration of the prototype startup, virtual laboratory environment, experimental trial selection, procedural guidance, and user interaction.

## Demonstration Content

The video provides a visual overview of:

- Local execution of the WebGL prototype.
- Navigation within the virtual laboratory environment.
- Selection of experimental trials.
- Procedural instructions displayed during the activity.
- Interaction with virtual laboratory equipment and materials.
- Visual representation of selected experimental phenomena.

## Purpose

The video is provided as supplementary material for the paper:

**Development and Preliminary Evaluation of a Virtual Prototype for Physical and Chemical Changes Laboratory Practice**

Its purpose is to provide a concise visual demonstration of the implemented prototype and complement the technical description presented in the manuscript.
