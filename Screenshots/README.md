# Screenshots

This folder contains visual materials from the virtual prototype developed for the laboratory practice **Physical and Chemical Changes**.

The screenshots provide supplementary visual documentation of the laboratory environment, user interfaces, virtual equipment, procedural guidance, and interaction mechanisms implemented in the prototype.

## Files

- `MainInterface.png` — Main prototype interface showing the experimental environment, trial selection panel, procedural guidance, and virtual tutor.
- `ExperimentSelection.png` — Interface used to select one of the nine experimental trials implemented in the prototype.
- `ExperimentProcedure.png` — Procedural instruction interface used to guide the user through the experimental sequence.
- `LaboratoryEquipment.png` — Virtual representation of laboratory equipment, materials, and resources used during the experimental activities.
- `VirtualLaboratory.png` — General view of the reconstructed virtual chemistry laboratory.
- `VirtualLaboratory_Overview.png` — Wider view of the virtual laboratory environment and workspace.
- `VirtualTutor.png` — Virtual tutor used to provide visual and audio guidance during the experimental activities.
- `ChemicalReaction.png` — Example of an experimental interaction involving the laboratory burner and visual representation of the corresponding phenomenon.
- `QuimiLab_Logo.png` — Project logo.

## Purpose

These images are provided as supplementary visual documentation of the prototype described in the paper:

**Development and Preliminary Evaluation of a Virtual Prototype for Physical and Chemical Changes Laboratory Practice**

The screenshots illustrate selected components and interactions of the implemented system and are not intended as evidence of learning effectiveness or objective experimental fidelity.
