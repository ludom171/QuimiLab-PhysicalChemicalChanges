# Prototype

This folder contains the executable WebGL build of the virtual prototype developed for the laboratory practice **Physical and Chemical Changes**.

## Contents

- `Build/` — WebGL build files generated by Unity.
- `StreamingAssets/` — Additional resources required by the prototype during execution.
- `TemplateData/` — Web interface resources generated for the WebGL build.
- `index.html` — Entry point of the WebGL application.
- `HTML5LaunchHelper.exe` — Lightweight local HTTP server included to facilitate execution of the prototype on Windows.

## How to Run

1. Open `HTML5LaunchHelper.exe`.
2. Start the local server.
3. Open the URL displayed by the launcher in a web browser.
4. Wait for the WebGL application to finish loading.

The prototype should be executed through a local HTTP server rather than opening `index.html` directly from the file system.

## Browser Compatibility

During development and preliminary evaluation, the prototype was tested using:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Opera

The prototype was evaluated on standard desktop and laptop computers available at the Centro de Química of the Universidad Central del Ecuador.

Formal minimum hardware requirements were not established during this preliminary study.

## Interaction

The current prototype uses:

- Keyboard for navigation.
- Mouse for camera control and interaction with virtual laboratory elements.
- Contextual interface controls for experimental actions.

## Source Code

The source code of the virtual prototype is not included in this repository because the software is part of an ongoing institutional research project at the Universidad Central del Ecuador.

The executable WebGL build is provided to support demonstration, verification, and reproducibility of the functionality described in the accompanying manuscript.
